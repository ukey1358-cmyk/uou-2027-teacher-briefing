# 사회 시나리오 — 2027학년도 대입전형 안내 교사설명회

울산대학교 입학처 교사설명회 사회자용 진행 대본을 휴대폰에서 바로 볼 수 있도록 만든 모바일 웹페이지입니다.

## 구성
- **대본** — 시간대별 전체 진행 대본 (상단 칩으로 순서 바로 이동)
- **순서** — 진행 순서표 + 행사 개요
- **대응** — 상황별 대응 멘트 (펼침형)
- **점검** — 사회자 사전 점검 체크리스트 (기기에 자동 저장)

## 특징
- 모바일 우선 레이아웃, 하단 탭 내비게이션, 노치/홈바 안전영역 대응
- 글자 크기 4단계 · 밝게/어둡게/자동 테마 (설정은 기기에 저장)
- 현재 시각에 해당하는 순서를 자동으로 강조 표시
- 단일 HTML 파일, 별도 빌드 없음
