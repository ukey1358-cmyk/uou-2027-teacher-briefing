# 인사말 — 학생부종합 교사 모의전형 프로그램

울산대학교 입학관리팀장 인사말 원고를 휴대폰에서 바로 보며 낭독할 수 있도록 만든 모바일 웹페이지입니다.

## 구성
- **인사말 원고** — 4개 단락(인사 · 취지와 프로그램 안내 · 기대 효과 · 맺음말), 호흡 단위로 줄바꿈
- **연출 메모** — 단락마다 시선·호흡·강조 지점 안내 (인쇄 시 자동 제외)
- **전문** — 줄바꿈 없는 전체 원문 + 복사 · 인쇄 버튼
- **개요** — 프로그램 및 순서 정보

## 특징
- 낭독 타이머 (탭: 시작·멈춤 / 길게 누르기: 초기화)
- 문장을 탭하면 읽는 위치가 표시됨
- 글자 크기 4단계 · 밝게/어둡게/자동 테마 (설정은 기기에 저장)
- 상단 스크롤 진행 표시줄, 노치/홈바 안전영역 대응
- 단일 HTML 파일, 별도 빌드 없음
